# TheWinner Business Intelligence — MVP v0.1

## Objectif
Prototype de copilote financier pour PME.

## Lancer en local
1. Installer Python 3.11+.
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## Données acceptées
CSV ou Excel. Colonnes reconnues automatiquement (français/anglais) :
- date / mois
- CA / chiffre_affaires / ventes
- dépenses / charges
- bénéfice / profit
- trésorerie / cash
- dettes / debt
- stock / stocks

## Roadmap
v0.1 : dashboard + ratios + anomalies.
v0.2 : moteur IA avec analyse narrative.
v0.3 : prévisions et scénarios.
v0.4 : comptes utilisateurs, stockage sécurisé, multi-entreprises.
v1.0 : plateforme web commerciale.

## Important
Ce prototype est un outil d'aide à l'analyse, pas un conseiller financier, comptable ou juridique.
